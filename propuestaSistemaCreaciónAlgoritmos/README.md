# Propuesta Sistema Creacion Algoritmos

Esta carpeta guarda la propuesta viva del nuevo sistema de creacion y ejecucion
de algoritmos.

Objetivo:
- pasar de un sistema centrado en `buy/sell/none`
- a un sistema donde la estrategia pueda decidir casi toda la logica de trading
- manteniendo la ejecucion tecnica centralizada

Regla de trabajo:
- cada avance del debate debe quedar reflejado aqui
- estas notas son de arquitectura, no de implementacion final
- si una decision cambia, se actualiza el documento correspondiente
