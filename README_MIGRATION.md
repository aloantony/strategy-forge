# Migración a Interfaz Moderna

## Instalación

```bash
pip install customtkinter
```

## Uso

### Opción 1: Probar la nueva interfaz moderna
```bash
python gui_modern.py
```

### Opción 2: Continuar con la interfaz actual
```bash
python gui.py
```

## Ventajas de CustomTkinter

1. **Apariencia Moderna**: Similar a Obsidian/Cursor
2. **Tooltips Mejorados**: Funcionan correctamente
3. **Temas Integrados**: Oscuro/claro automático
4. **Componentes Modernos**: Botones, inputs, etc. más atractivos
5. **Mejor UX**: Animaciones y transiciones suaves
