Interfaz (GUI)

gui_charts.py define la clase TradingBotGUI, construida sobre Lightweight Charts (estilo TradingView). Se lanza con run(). Presenta estado y captura intención; delega los procesos en los servicios y runtimes.

★ La GUI no orquesta procesos

El bot en vivo se ejecuta en un hilo (bot_loop), pero la lógica reutilizable vive en src/application/ y los runtimes; la GUI solo los invoca. Ver Arquitectura.

Modelo de hilos

Hilo principal
Montaje de la UI y el chart (run).
Hilo del bot
bot_loop, lanzado por start_bot / _toggle_strategy_run; analiza estrategias y ejecuta señales.
Quote updater
start_quote_updater → _quote_loop: precios en tiempo real.
Callback pump
start_callback_pump → _callback_loop: procesa eventos venidos del JS.

Puente Python ↔ JavaScript

Los botones del chart llaman a window.callbackFunction("<handler>_~_<evento>[;;;payload]"); el separador _~_ distingue el handler del evento y ;;; separa los argumentos (a menudo JSON URL-encoded). El callback pump de Python despacha esos eventos a métodos como _on_backtest_run o on_side_panel_event.
