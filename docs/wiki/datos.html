Datos y ejecución

Datos de mercado

Dos contratos abstractos aíslan al sistema de sus fuentes: datos live enriquecidos para el runtime/GUI, y datos históricos para el backtesting. Las implementaciones concretas (MT5, Dukascopy, ficheros) se eligen por fábrica.

Contratos (src/data/interface.py)

InterfazMétodoDevuelve
IDataFeedget_enriched_df(symbol, timeframe, bars)DataFrame con indicadores ya calculados.
IHistoricalDataSourceget_rates_df(symbol, timeframe, start, end)OHLCV crudo en el rango.
IHistoricalDataSourceget_instrument_info(symbol)InstrumentInfo o None.

Columnas derivadas (data_feed.py)

get_rates_df() obtiene velas de MT5 con copy_rates_from_pos y marca time en UTC. La cadena add_* añade los indicadores. Estas son las columnas exactas que produce cada función:

FunciónColumnas que añade
get_rates_dftime, open, high, low, close, tick_volume (y spread/real_volume si MT5 los entrega)
add_source_columnsOHLC4, HLC3, HL2, CLOSE y h_set, l_set (según SOURCE_MODE)
add_baseline_bandsaverage (SMA), atr, upper, lower
add_supertrendsupertrend, supertrend_dir (1/-1/0), supertrend_up, supertrend_down (y hma si use_hma)
add_tcitci, tci_signal, tci_hist

MT5DataFeed.get_enriched_df aplica esa cadena completa internamente, así que el consumidor recibe el DataFrame listo. También están weighted_moving_average y hull_moving_average como helpers.

Datos históricos y fábrica

build_data_source acepta "mt5" o "dukascopy"; para Dukascopy traduce el símbolo a su canónico vía symbols.json y falla temprano si falta la dependencia o el mapeo. FileProvider existe pero no está cableado en la fábrica.

Fuentes históricas

FuenteCómo obtiene los datos
MT5HistoricalDataSourcemt5.copy_rates_range; resuelve el ticker MT5 con providers.mt5 de symbols.json. get_instrument_info lee symbol_info.
DukascopyHistoricalDataSourcedukascopy_python.fetch(..., offer_side="bid"); mapea timeframe a 1MIN…1DAY; normaliza el schema y rellena spread/real_volume a 0; InstrumentInfo desde el bloque instrument de symbols.json.
FileProviderLee cache/file/<symbol>/<timeframe>/*.parquet|*.csv, concatena, ordena por time y filtra al rango.

Registro de símbolos (symbols.json)

Cada símbolo canónico mapea a su ticker por proveedor y, para fuentes sin metadata propia, incluye un bloque instrument. Ejemplo real del repositorio:

"GER40": {
  "providers": { "mt5": "#Germany40", "dukascopy": "E_DAAX", "file": "GER40" },
  "instrument": { "tick_size": 0.1, "tick_value": 1.0, "point": 0.1, "digits": 1, ... }
},
"EURUSD": {
  "providers": { "mt5": "EURUSD", "dukascopy": "EUR/USD", "file": "EURUSD" },
  "instrument": { "tick_size": 0.00001, "point": 0.00001, "digits": 5, ... }
}
