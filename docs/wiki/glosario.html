Glosario

Vocabulario derivado del código, agrupado por área. Cada término aparece tal y como lo usa el repositorio.

Estrategias y señales

TérminoSignificado
StrategyMódulo Python en strategies/ que recibe un DataFrame y devuelve una señal o un payload.
SignalValor normalizado: buy sell none
Signal payloadDict con signal, reason y campos como pyramiding, atr_value, dynamic_sizing, volume_ratio.
Closed candleÚltima vela cerrada (df.iloc[-2]); las estrategias deciden sobre ella.
PARAMSEsquema de parámetros editables de una estrategia ({type, default, min, max, label}).
Magic numberIdentificador con el que MT5 agrupa las órdenes de una estrategia.
PyramidingAñadir tamaño a una posición ganadora (solo largos en trading.py).

Runtime v1 y planes

TérminoSignificado
decide()Función de una estrategia v1 que devuelve {plan, next_state}.
ContextDict que recibe decide(): run, clock, market, instrument, account, portfolio, execution, engine.
PlanDecisión estructurada con una lista de actions y un reason.
Action / Normalized actionOperación pedida (open/close/reduce/move SL-TP…) y su versión validada por el PlanInterpreter.
LegacyStrategyAdapterEnvuelve una estrategia v0 y la presenta como decide().
Execution report / Action reportResultado persistido de ejecutar un plan y de cada acción.
State storeCarga/guarda el estado de la instancia con revisión (concurrencia optimista).

Recursos canónicos y persistencia

TérminoSignificado
Entry groupGrupo canónico de entradas relacionadas.
LegPosición o parte de posición (volumen, SL/TP, estado).
FillEjecución real o simulada (open / reduce / close).
Pending orderOrden pendiente (limit/stop) modelada en persistencia.
Event logRegistro append-only de eventos del runtime.
Unit of WorkTransacción (uow.immediate()) con commit al salir y rollback ante error.

Datos y broker

TérminoSignificado
Data feedFuente live enriquecida (IDataFeed.get_enriched_df).
Data sourceFuente histórica para backtest (IHistoricalDataSource): MT5, Dukascopy o File.
Broker adapterImplementación de IBrokerAdapter; hoy MT5BrokerAdapter.
Símbolo canónicoNombre neutral en symbols.json que se traduce al ticker de cada proveedor.
Filling modePolítica de ejecución del broker (FOK / IOC / RETURN); se negocia con reintentos.
Comentario de ordenTA|o|s=<estrategia>|r=<motivo> (≤ 31 caracteres) para atribuir trades.

Indicadores y métricas

TérminoSignificado
OHLC4 / HLC3 / HL2Precios agregados de la vela usados como fuente (SOURCE_MODE).
ATRAverage True Range: volatilidad; base de bandas, stops y sizing.
Supertrend / TCI / HMAIndicadores extra calculados por data_feed.py (principalmente para la GUI).
Warmup barsVelas previas para inicializar indicadores en backtest (por defecto 500).
DrawdownCaída desde un máximo de equity; max_drawdown es la peor observada.
Profit factor / ExpectancyBeneficio bruto ÷ pérdida bruta; y resultado medio esperado por operación.
Riesgo agregadocheck_aggregate_risk: límite del 3% del balance sobre el riesgo total.
Fuente (código): strategy_runtime.py, src/runtime/*, src/persistence/schema.py, data_feed.py, trading.py, backtesting/runtime.py.
