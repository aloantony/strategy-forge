Strategy Builder

strategy_builder/generator.py genera un módulo de estrategia (.py + .json) a partir de una configuración JSON validada. Es lo que usa el editor visual de la GUI. El módulo no es importado por las estrategias (regla de aislamiento).

Puntos de entrada

FunciónQué hace
generate_strategy_file(config, …)Renderiza y escribe strategy_<name>.py + .json de forma atómica.
render_strategy_source(config)Devuelve el código Python como string; valida con ast.parse antes de retornar.
build_strategy_module(config, …)Compila el módulo en memoria (preview del Builder, sin escribir a disco).
handle_save_new / handle_save_editFlujos completos de crear/editar: sanea el nombre, gestiona colisiones, asigna/preserva el magic number.
validate_strategy_config(config, …)Valida (y normaliza) la configuración; lanza ValidationError.

Excepciones: ValidationError, NameCollisionError (subclase) y GeneratorError (fallo al renderizar/escribir).

Esquema de la configuración

CampoRegla (real)
schema_versionDebe ser 1.
nameRegex ^[a-z][a-z0-9_]*$.
display_name1–80 caracteres.
description≤ 500 caracteres.
timeframeUno de M1, M5, M15, M30, H1, H4, D1.
magic_numberEntero 10000–99999.
indicators[]Cada uno {id, pre_computed, params, columns} con id válido.
buy_condition / sell_conditionÁrbol de condiciones (ver abajo).
payload_extra_fields[]Campos extra para el payload (literal o columna).

Indicadores y operadores válidos

EMARSIBB DONCHIANATRVWAP VOLUME_RATIOSMAHMA SUPERTRENDTCIADX_DI

Operadores permitidos: <　>　<=　>=　==　!=. Las columnas siempre disponibles (ALWAYS_AVAILABLE_COLUMNS) incluyen OHLC, OHLC4/HLC3/HL2, tick_volume, average/atr/upper/lower, hma, supertrend* y tci*.

Árbol de condiciones

// hoja
{ "type": "condition", "left": "adx_14", "op": ">", "right": 25 }

// grupo (mínimo 2 hijos)
{ "type": "AND", "children": [ {...}, {...} ] }   // o "OR"

El generador emite dos formas de cada condición: una escalar (df.iloc[-2]["col"]) para get_last_signal y una vectorizada (Series booleanas) para compute_signals.

Qué genera

El código resultante contiene, en orden: docstring, import pandas, constantes de módulo (TIMEFRAME, MAGIC_NUMBER, periodos), bloque PARAMS, OBJECT_TREE_ITEMS, DATA_WINDOW_FIELDS, helpers (_rsi, _atr, _adx_di, …), prepare_dataframe (si hay indicadores a calcular), compute_signals, get_last_signal_payload y get_last_signal. Antes de escribir nada, el código pasa por ast.parse.
