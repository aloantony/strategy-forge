Strategy Forge · MetaTrader 5

Bot de trading modular con GUI estilo TradingView

Bot para MetaTrader 5 que ejecuta varias estrategias enchufables a la vez, las activa o desactiva sin reiniciar y permite hacer backtesting desde la interfaz o la terminal. Esta wiki está construida analizando el código fuente: cada página cita los módulos .py de los que sale su contenido.

MetaTrader 5 Python 3.9+ Estrategias enchufables Backtesting Runtime v1 (planes)

Qué puedes hacer

◰

Operar desde la GUI

Gráfico de velas, indicadores, Data Window y panel de estrategias (gui_charts.py).

⛁

Varias estrategias a la vez

Análisis concurrente con scheduling justo; cada estrategia es un módulo Python aislado.

↻

Activar sin reiniciar

Enciende o apaga estrategias en caliente desde la pestaña Estrategias.

◷

Backtesting reproducible

Mismo motor desde GUI o CLI, con datos de MT5 o Dukascopy.

Flujo general

La GUI es la entrada visual; la lógica de proceso vive en servicios reutilizables y en los runtimes.

⚑ Antes de lanzar el bot

Abre MetaTrader 5 y deja la cuenta conectada. El bot usa MT5 directamente para datos y órdenes (mt5_connection.initialize_mt5() falla si MT5 no está disponible).

Tres modos de ejecución

ModoComandoPara qué
GUIpython gui_charts.pyOperación visual y control en vivo (entrada principal).
Headlesspython main.pyLoop de trading sin GUI, útil para depurar.
Backtest CLIpython -m backtesting runtime --helpBacktesting reproducible desde terminal.

Inicio rápido (GUI)

  1. Instala dependencias: pip install -r requirements.txt (o python install.py).
  2. Ajusta config.py: SYMBOL, LOT, SL_POINTS, TP_POINTS, ACTIVE_STRATEGIES.
  3. Lanza la interfaz: python gui_charts.py
  4. En la pestaña Estrategias, pulsa Iniciar motor.
  5. Monitoriza operaciones y ajusta en tiempo real.

├── backtest.py            Backtester legacy (en desuso)
├── install.py             Instalador cross-platform
│
├── src/
│   ├── mt5_import.py       Import condicional MetaTrader5 / mt5linux
│   ├── application/        Servicios de proceso (BacktestService)
│   ├── broker/             IBrokerAdapter + MT5BrokerAdapter + comment

⚠ Recomendaciones de seguridad

Prueba primero en cuenta demo. Empieza con lotaje bajo. Verifica SYMBOL, lote y stops de config.py antes de operar en real.
