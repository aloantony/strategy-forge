Entornos y dependencias

El bot necesita un MetaTrader 5 conectado para datos y órdenes. En Windows habla con MT5 directamente; fuera de Windows lo hace contra un Windows remoto vía mt5linux. La persistencia es un fichero SQLite local.

Requisitos

Python
3.9 o superior (lo verifica install.py).
MetaTrader 5
Terminal con la cuenta conectada y el símbolo visible en Market Watch.
Instalación
pip install -r requirements.txt — o python install.py, que valida la versión e imprime los comandos por plataforma.

Entorno principal (Windows)

El proceso Python usa el paquete MetaTrader5 para datos y órdenes, persiste en trading_bot.db y opcionalmente descarga histórico de Dukascopy.

Mac / Linux (MT5 remoto)

MT5 no corre nativo fuera de Windows. src/mt5_import.py detecta la plataforma: en win32 importa MetaTrader5; en otro caso instancia mt5linux.MetaTrader5(host, port) con MT5LINUX_HOST/MT5LINUX_PORT.

Según install.py, en el Windows remoto se arranca el servidor:

pip install mt5linux
python -c "from mt5linux import MetaTrader5Server; MetaTrader5Server().start()"
ℹ GUI en Linux

install.py recuerda que la GUI necesita libwebkit2gtk: Ubuntu/Debian sudo apt install libwebkit2gtk-4.0-dev · Fedora webkitgtk4 · Arch webkit2gtk.

⚑ Antes de arrancar

MT5 abierto y con cuenta conectada. El símbolo debe existir y estar visible en Market Watch; su prefijo depende del broker (p.ej. #Germany40 vs DE40).
