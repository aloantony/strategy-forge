# C4 Architecture

Estos diagramas siguen el modelo C4, pero usan `flowchart` de Mermaid para evitar la sintaxis C4 experimental.

## System Context

```mermaid
flowchart LR
  Trader["Person: Trader"]
  Developer["Person: Developer"]
  Agent["Person/System: Coding Agents"]
  TA["Software System: Trading Agent"]
  MT5["External System: MetaTrader 5"]
  Dukascopy["External System: Dukascopy"]
  FS["External System: Local Files / SQLite"]

  Trader -->|Operates and monitors| TA
  Developer -->|Changes and reviews| TA
  Agent -->|Plans, implements, reviews| TA
  TA -->|Market data and orders| MT5
  TA -->|Historical candles| Dukascopy
  TA -->|Strategies, configs, DB, docs| FS
```
